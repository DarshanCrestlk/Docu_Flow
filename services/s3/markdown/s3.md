# S3 Service (`s3`)

**Source:** `services/s3/s3.service.js`  
**Mixin implementation:** `mixins/libs/s3.mixin.js`

## Role

Handles **file upload to AWS S3**, **in-place object updates**, and **pre-signed URL** generation. Used by the PDF forms flow and general document storage. Streams multipart uploads to a local temp directory, then uploads to S3 under a **company-name prefix**.

## Mixins

| Mixin | Purpose |
|-------|---------|
| `S3mixin` | `upload`, `deleteFile`, `updateFileData`, `generateSignedURL`, SES helpers |
| `helperMixin` | `verifyAndExtractCompanyId`, company context |

## Actions

### `uploadToS3`

`authorization: false` (custom auth inside handler).

**Auth paths:**

1. **Office API:** `ctx.meta.officeAPI` skips tenant checks.
2. **PDF signer:** `ctx.meta.$params.pdf_token` → `broker.call("pdfForms.verifyPDFToken")` → sets `company_id`, `is_public`.
3. **Default:** `verifyAndExtractCompanyId(ctx)` (JWT / session).

**Flow:**

1. Resolve `company_id`; load company via `companies.getById`.
2. Stream request body to `assets/uploads/{timestamp}.{filename}`.
3. Optional ConvertAPI conversion when `convert` + `convert_type` multipart flags set.
4. Call `this.upload(fileInfo, dir, companyName, uniqueName, isThumbnailRequired)`.
5. Return `url`, `fileName`, `size`, `Key` (and optional thumbnail fields).

**Multipart fields (examples):** `location`, `isThumbnailRequired`, `convert`, `convert_type`.

### `updateToS3`

`authorization: false`.

- Reads stream into buffer.
- Updates existing S3 object via `updateFileData(file_name, key, mime_type, location, buffer)`.

### `getSignedURL`

- Params: `key`, `id`
- Returns time-limited signed URL for client download.

### `deleteFileFromS3` (commented)

Legacy REST delete by URL — not active in current schema.

## S3 mixin methods (shared with `pdfForms`)

| Method | Behavior |
|--------|----------|
| `upload` | `companyName/images/{dir}/{timestamp}.{filename}`; optional `auto-delete=24h` tag |
| `fileDeleteFromS3` | Delete by Key or parsed URL |
| `updateFileData` | Replace object body |
| `generateSignedURL` | Presigned GET |
| `copyObject` | Used by pdfForms for document copies |

## Environment variables

- `AWS_S3_ACCESS_KEY_ID`
- `AWS_S3_SECRET_ACCESS_KEY`
- `AWS_S3_REGION`
- `AWS_S3_BUCKET_NAME`

## Integration with pdfForms

Public signers upload signatures/files using **recipient token** verification before S3 upload, without a full user session.

## Operational notes

- Local temp files are deleted after upload unless `preserveAfterUpload` is true.
- Thumbnail generation (Puppeteer) is commented out in `uploadToS3`.
- Errors throw `MoleculerError` with status from upstream verification.
